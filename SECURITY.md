# Security Policy

## Reporting a vulnerability

Please do not disclose vulnerabilities in public issues, discussions, or pull requests.

Report them privately through **Security → Report a vulnerability** in this repository and include, where possible:

- The affected relay version and platform (Windows, Linux, macOS, or Docker)
- Steps to reproduce and the impact
- Any known mitigation

Reports are acknowledged and assessed as soon as possible; details are published after a fix is released.

## Scope

This repository contains only the relay service. Report issues in the other components to their repositories:

- [MyCodex](https://github.com/jintonglu6688/MyCodex) (Windows client and remote host)
- [MyCodex-android](https://github.com/jintonglu6688/MyCodex-android)
- [MyCodex-auth-host](https://github.com/jintonglu6688/MyCodex-auth-host)

## Supported versions

Security fixes are provided for the latest release only.
